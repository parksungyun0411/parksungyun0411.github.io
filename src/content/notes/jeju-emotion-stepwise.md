## 데이터가 없다는 것에서 시작

졸업 프로젝트 주제는 제주어 문장의 감정 분류였습니다. 문제는 모델이 아니라 재료였습니다. 감정 라벨이 붙은 제주어 데이터는 사실상 없고, 표준어용 감정 모델은 제주어 특유의 어휘와 어미를 처리하지 못합니다. 그래서 모델보다 학습 데이터를 먼저 만들기로 했습니다.

AI Hub의 제주어·표준어 병렬 코퍼스와 한국어 단발성 대화 데이터를 정제하고, GPT-4o로 문장마다 일곱 감정(중립·행복·슬픔·분노·놀람·공포·혐오) 중 하나를 붙였습니다. 자동으로 달린 라벨을 그대로 쓰지 않고 표본을 직접 뜯어보며 검수하는 절차를 따로 뒀습니다. 라벨이 흔들리면 뒤 단계가 전부 흔들리기 때문입니다. 그렇게 127,324행의 학습 데이터를 만들고 7클래스를 균형 맞춘 뒤 7:1:2로 층화 분할했습니다. 시드를 고정해 이후의 모든 실험이 같은 test set을 보게 했습니다.

## 왜 정확도가 아니라 F1-Macro인가

감정 분류는 클래스마다 빈도와 난이도가 다릅니다. 중립이 많은 데이터에서 정확도는 중립만 잘 맞혀도 올라갑니다. 우리가 알고 싶은 것은 공포나 혐오 같은 적은 클래스까지 고르게 맞히는지였으므로, 클래스별 F1을 단순 평균하는 F1-Macro를 처음부터 기준으로 정했습니다. 기준을 먼저 정해 두면 단계마다 "좋아졌다"는 말을 같은 자로 잴 수 있습니다.

## 고전 ML을 먼저 돌린 이유

딥러닝으로 바로 가지 않고 TF-IDF와 N-gram(1~3) 특성으로 Logistic Regression, SVM, Random Forest, Naive Bayes 네 가지를 같은 조건에서 돌렸습니다. 제주어 균형 데이터에서 최고 F1-Macro는 Naive Bayes의 0.2957이었습니다. 이 결과를 지우지 않고 "표면 통계로는 방언 감정을 읽을 수 없다"는 한계를 숫자로 박아 둔 채 넘어갔습니다. 나중에 사전학습 언어 모델로 접근을 바꾼 결정의 근거이고, 최종 수치가 얼마나 올라왔는지를 말할 때의 출발점입니다.

## 같은 test set 위에 쌓은 7단계

방향을 바꿔도 한 번에 되지는 않았습니다. 단계마다 결과를 보고 다음 단계를 정했습니다.

| 단계 | 기법 | Test F1-Macro |
| :---: | --- | :---: |
| 1 | KR-BERT 베이스라인 (전처리 없음) | 0.4733 |
| 2 | + 데이터 밸런싱 (오버샘플링) | 0.5833 |
| 3 | + Dual-Gated KR-BERT (제주어·표준어 shared 인코더 + 게이팅 융합) | 0.6158 |
| 4 | + 제주어 토크나이저 최적화 (제주어 토큰 추가) | 0.7184 |
| 5 | + DAPT (제주어 말뭉치 MLM 재학습) | 0.7456 |
| 6 | + Hard Mining (loss 상위 20% 가중) | 0.8003 |
| 7 | + 앙상블 (KoELECTRA + Dual KR-BERT) | **0.8404** |

![제주어 감정 분류 7단계 파이프라인 도식](/projects/jeju-pipeline.png)

가장 큰 폭은 3단계와 4단계 사이에서 나왔습니다. 제주어 문장과 표준어 문장을 같은 인코더에 넣고 게이트가 두 표현의 기여도를 학습하게 한 구조가 방언 문맥을 잡기 시작했고, 토크나이저에 제주어 토큰을 추가하자 조각나던 어미가 온전한 토큰으로 들어갔습니다. 마지막 단계의 앙상블은 성격이 다른 두 모델(제주어 단독 입력 KoELECTRA와 병렬 입력 Dual KR-BERT)의 확률을 가중 결합한 것으로, 가중치는 그리드 서치로 찾았습니다.

## 수치의 범위를 그대로 적는다

표의 수치는 최종 발표 실험 기준입니다. 공개 저장소의 재현 코드는 이미 밸런싱과 정제가 끝난 데이터를 쓰기 때문에 1단계 재현치가 0.7593으로 더 높게 시작합니다. 1~2단계의 효과가 데이터에 미리 반영된 셈입니다. 저장소 안에서 코드로 재현해 확인한 것은 KR-BERT 단계까지이고, 원본 데이터(AI Hub 라이선스)와 학습된 가중치는 저장소에 넣지 않았습니다. 재현하려면 AI Hub에서 데이터를 받아 직접 학습해야 합니다.

이 범위를 적는 이유는 단순합니다. 0.84라는 숫자가 어디까지 확인된 값인지 모르면 다음 사람이 같은 실험을 다시 해야 합니다. 그 뒤로는 점수가 막히면 기법을 더하기 전에 접근이 맞는지부터 확인하고, 숫자를 적을 때는 그 숫자가 확인된 범위를 함께 적습니다.
