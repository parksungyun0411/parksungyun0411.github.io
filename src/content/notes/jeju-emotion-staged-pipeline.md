## 출발점: 라벨이 없는 언어

제주어에는 감정 라벨이 붙은 공개 데이터가 없었습니다. 그래서 AI Hub의 제주어/표준어 병렬 코퍼스(텍스트 파일 4,600여 개)와 한국어 단발성 대화 데이터셋을 모아 정제하고, GPT-4o API로 7감정(중립·기쁨·슬픔·분노·놀람·공포·혐오)을 자동 라벨링한 뒤 수동 검증을 병행했습니다. 딥러닝 학습에 쓴 최종 데이터는 127,324행입니다.

라벨이 모델 출력이라는 점은 처음부터 한계로 안고 갔습니다. 발표 실험은 이를 위해 신뢰도 하위 30% 샘플을 걸러내는 노이즈 필터링을 썼지만, 수동 검증을 몇 건에 했는지는 저장소에 기록되어 있지 않습니다.

## 정확도 대신 F1-Macro를 본 이유

클래스가 불균형한 데이터(72,879행)에서는 중립이 48.5%를 차지합니다. 이 데이터로 고전 ML을 돌리면 지표가 서로 다른 이야기를 합니다.

| 데이터 | 최고 모델 | Accuracy | F1-Macro | F1-Weighted |
|---|---|---:|---:|---:|
| 불균형 (72,879행) | SVM | 0.5172 | 0.2326 | 0.4281 |
| 균형 (12,950행) | Naive Bayes | 0.2977 | 0.2957 | 0.2958 |

불균형 데이터의 정확도 0.52는 다수 클래스인 중립을 많이 맞힌 결과에 가깝고, 클래스 크기로 가중하는 F1-Weighted도 같은 쪽으로 기웁니다. 공포(2.5%)나 혐오(3.1%) 같은 소수 감정을 얼마나 맞히는지는 클래스별 F1을 단순 평균하는 F1-Macro에서만 드러납니다. 그래서 이후 모든 단계의 기준 지표를 F1-Macro로 정했습니다.

## 고전 ML을 먼저 돌린 이유

딥러닝으로 바로 가지 않고 TF-IDF(1~3-gram, 최대 30,000 특성)에 로지스틱 회귀·SVM·랜덤 포레스트·나이브 베이즈 네 종을 같은 조건으로 붙였습니다. 균형 데이터에서 네 모델의 F1-Macro는 0.2771~0.2968에 모였습니다. 모델을 바꿔도 0.30 근처를 넘지 못한다는 것을, 표면 통계만으로는 방언의 문맥과 감정 경계를 잡기 어렵다는 신호로 읽었습니다. 이 결과를 딥러닝으로 전환하는 근거로 삼았습니다.

## 7단계를 비교 가능하게 쌓기

![제주어 감정 분류 7단계 개선 파이프라인 — KR-BERT 베이스라인에서 KoELECTRA 앙상블까지 단계별 F1-Macro (최종 발표 실험 기준)](/notes/jeju-pipeline.png)

단계마다 데이터 분할이 달라지면 점수가 오른 것이 기법 덕인지 분할 운인지 구분할 수 없습니다. 그래서 분할을 seed 42로 고정한 Stratified 7:1:2(Train 89,118 / Val 12,732 / Test 25,463)로 정하고, 모든 단계가 같은 test set을 쓰게 했습니다. 마지막 앙상블 단계는 두 모델의 test 확률을 가중 결합하므로, 같은 test set이어야 결합 자체가 성립합니다.

| 단계 | 기법 | Test F1-Macro |
|---|---|---:|
| 1 | KR-BERT 베이스라인 (전처리 없음) | 0.4733 |
| 2 | + 데이터 밸런싱 (오버샘플링) | 0.5833 |
| 3 | + Dual-Gated KR-BERT | 0.6158 |
| 4 | + 제주어 토크나이저 최적화 | 0.7184 |
| 5 | + DAPT (제주어 MLM 재학습) | 0.7456 |
| 6 | + Hard Mining (loss 상위 20% 가중) | 0.8003 |
| 7 | + KoELECTRA 앙상블 | 0.8404 |

3단계의 Dual-Gated 구조는 제주어 문장과 표준어 문장을 같은 KR-BERT 인코더에 통과시키고, 게이트 `g = σ(W·[h_jeju; h_std] + b)`가 두 표현을 얼마나 섞을지 학습합니다. 병렬 코퍼스라서 표준어 문장을 보조 입력으로 쓸 수 있다는 점을 구조에 반영한 것입니다. 최종 모델은 이 브랜치와 제주어만 받는 KoELECTRA 브랜치의 확률을 `p = α·p_dual + (1-α)·p_single`로 결합하고, α는 그리드 서치로 정했습니다.

## 아직 확인하지 못한 것

**0.8404는 저장소에서 재현되지 않았습니다.** 위 표는 최종 발표 실험의 수치입니다. 공개 저장소의 재현 코드로는 단일 KR-BERT까지 확인했고(Test F1-Macro 0.7593, Accuracy 0.7729), Dual-Gated 단계는 1 epoch 검증 F1-Macro 0.7042까지만 기록되어 있습니다. Hard Mining, KoELECTRA, 앙상블 재현은 아직입니다.

**재현 1단계가 발표 1단계보다 높게 시작합니다.** 재현에 쓴 데이터가 이미 밸런싱·정제된 상태여서, 발표의 "전처리 없음" 베이스라인(0.4733)보다 훨씬 높은 0.7593에서 출발합니다. 발표의 1~2단계 효과가 데이터에 선반영된 셈이라, 재현 결과로 단계별 개선 폭을 그대로 다시 읽을 수는 없습니다.

**0.30과 0.84는 같은 데이터에서 나온 숫자가 아닙니다.** 고전 ML의 0.2957은 12,950행 균형 데이터, 딥러닝 결과는 127,324행 데이터에서 나왔습니다. 데이터 규모가 다르므로 두 수치의 차이를 모델 차이만으로 해석하면 과장이 됩니다. 같은 127,324행에 고전 ML을 다시 돌려 보는 것이 남은 검증입니다.

**강한 감정과 약한 감정의 격차가 큽니다.** 재현한 단일 KR-BERT 기준 감정별 F1은 공포 0.954, 혐오 0.909, 놀람 0.867인 반면 행복 0.602, 중립 0.489입니다. 의미가 겹치는 다수 감정끼리 혼동이 남아 있습니다.

원본 데이터(AI Hub 라이선스)와 학습된 가중치는 저장소에 없으므로, 이 결과를 재현하려면 데이터를 직접 내려받아 학습해야 합니다.
